Build the foundational infrastructure for Discord bot integration: extend config to support Discord settings, create the TerminalBot class with explicit routing API, rewrite the entry point for dual WS+Discord operation, and add AgentManager callbacks for agent lifecycle events.

Purpose: Establishes the core bot object, routing contract (get_agent_for_channel, _find_channel_for_agent), and startup sequence that all slash commands and notifications depend on. Phase 3's /run command will use the routing API defined here.

**Routing contract for Phase 3:** This plan creates `get_agent_for_channel(channel_id) -> str | None` and `_find_channel_for_agent(machine_name) -> str | None` as the routing API. **ROUT-02 clarification:** Channel-to-agent mapping starts as static config in config.json (ROUT-02). Auto-channel creation (D-14, Plan 02) extends this config at runtime by appending new entries and persisting via save_config(). The config file remains the source of truth.

1. Create `bot/discord_bot.py` with class `TerminalBot(commands.Bot)`:

```python
import asyncio
import discord
from discord.ext import commands
from loguru import logger

class TerminalBot(commands.Bot):
    def __init__(self, agent_manager: AgentManager, config: BotConfig):
        intents = discord.Intents.default()  # D-19: no message_content, no members
        super().__init__(command_prefix="!", intents=intents)  # prefix unused per D-04
        self.agent_manager = agent_manager
        self.bot_config = config
        self._ready = asyncio.Event()  # track Discord readiness for notifications

    async def setup_hook(self):
        """Sync slash commands to allowed guilds (D-11: guild commands, instant sync).
        Also registers global interaction check for guild allowlist (AUTH-04 at runtime)."""
        # Load cogs (will be created in Plan 02)
        try:
            await self.load_extension("bot.cogs.general")
        except Exception as e:
            logger.warning(f"Could not load general cog: {e}")

        # AUTH-04 RUNTIME ENFORCEMENT (addresses review concern #4):
        # This global interaction check runs on EVERY interaction, not just at startup.
        # setup_hook only syncs commands to allowed guilds (defense-in-depth layer 1).
        # This check is the authoritative runtime gate (defense-in-depth layer 2).
        @self.tree.interaction_check
        async def global_interaction_check(interaction: discord.Interaction) -> bool:
            """Runtime guild allowlist enforcement. AUTH-04.
            NOTE: This is the PRIMARY security gate. default_permissions on commands
            is UI hiding only (defense-in-depth layer 3, not authoritative)."""
            if interaction.guild_id not in self.bot_config.allowed_guild_ids:
                return False  # silently reject unauthorized guilds
            return True

        # Sync to each allowed guild (defense-in-depth: only allowed guilds get commands)
        for guild_id in self.bot_config.allowed_guild_ids:
            guild = discord.Object(id=guild_id)
            self.tree.copy_global_to(guild=guild)
            try:
                await self.tree.sync(guild=guild)
                logger.info(f"Synced commands to guild {guild_id}")
            except Exception as e:
                logger.error(f"Failed to sync commands to guild {guild_id}: {e}")

    async def on_ready(self):
        logger.info(f"Discord bot connected as {self.user}")
        self._ready.set()

    def setup_agent_callbacks(self):
        """Wire AgentManager callbacks to Discord notification methods."""
        self.agent_manager.on_agent_connect = self._on_agent_connect
        self.agent_manager.on_agent_disconnect = self._on_agent_disconnect

    async def _on_agent_connect(self, machine_name: str, platform: str):
        """Called by AgentManager when an agent registers. Sends notification to mapped channel.
        Addresses review concern #6: wrapped in try/except for error isolation."""
        if not self._ready.is_set():
            return  # Discord not ready yet, skip notification (Pitfall 5)
        channel_id = self._find_channel_for_agent(machine_name)
        if channel_id is None:
            # D-14: auto-create channel (completed in Plan 02)
            pass
        else:
            channel = self.get_channel(int(channel_id))
            if channel:
                try:
                    await channel.send(f"\U0001f7e2 **{machine_name}** connected ({platform})")
                except Exception as e:
                    logger.error(f"Failed to send connect notification for {machine_name}: {e}")

    async def _on_agent_disconnect(self, machine_name: str):
        """Called by AgentManager when agent disconnects. Sends notification to mapped channel.
        Addresses review concern #6: error handling on disconnect notification too."""
        if not self._ready.is_set():
            return
        channel_id = self._find_channel_for_agent(machine_name)
        if channel_id:
            channel = self.get_channel(int(channel_id))
            if channel:
                try:
                    await channel.send(f"\U0001f534 **{machine_name}** disconnected")
                except Exception as e:
                    logger.error(f"Failed to send disconnect notification for {machine_name}: {e}")

    def _find_channel_for_agent(self, machine_name: str) -> str | None:
        """ROUTING API: Look up channel ID for a given machine_name.
        Reverse lookup from channel_mapping (which maps channel_id -> machine_name).
        Used by notification system and will be used by Phase 3 for response routing."""
        for ch_id, name in self.bot_config.channel_mapping.items():
            if name == machine_name:
                return ch_id
        return None

    def get_agent_for_channel(self, channel_id: int) -> str | None:
        """ROUTING API (ROUT-01): Look up machine_name for a given Discord channel_id.
        Returns None if channel is not mapped to any agent.
        Phase 3's /run command will call this to determine which agent executes a command.
        Channel IDs from Discord are int; config stores them as string keys (Pitfall 3)."""
        return self.bot_config.channel_mapping.get(str(channel_id))
```

def _remove_agent(self, machine_name: str) -> None:
    """Remove agent from tracked dict and fire disconnect callback."""
    if machine_name in self.agents:
        if self.on_agent_disconnect:
            try:
                asyncio.create_task(self.on_agent_disconnect(machine_name))
            except Exception as e:
                logger.error(f"Error scheduling on_agent_disconnect callback: {e}")
        del self.agents[machine_name]
        logger.info(f"Agent disconnected: {machine_name}")

```python
"""Entry point: python -m bot"""
import asyncio
import signal
import sys

from loguru import logger
from websockets.asyncio.server import serve

from bot.config import load_bot_config
from bot.discord_bot import TerminalBot
from bot.server import AgentManager


async def run():
    config = load_bot_config()

    manager = AgentManager(config)

    # D-02: WS server starts first (agents can connect immediately)
    ws_server = await serve(manager.handler, config.ws_host, config.ws_port)
    logger.info(f"WebSocket server started on ws://{config.ws_host}:{config.ws_port}")

    heartbeat_task = asyncio.create_task(manager._heartbeat_loop())

    bot = TerminalBot(agent_manager=manager, config=config)
    bot.setup_agent_callbacks()

    try:
        # Addresses review concern #7: if Discord login fails, we shut down cleanly
        # rather than leaving WS server running in degraded mode.
        await bot.start(config.discord_token)
    except discord.LoginFailure as e:
        logger.error(f"Discord login failed: {e}. Check DISCORD_BOT_TOKEN in bot/.env")
        # Startup failure policy: exit process. Do NOT run degraded transport-only mode.
        # Rationale: bot without Discord is useless for this project's purpose.
    except KeyboardInterrupt:
        pass
    except Exception as e:
        logger.error(f"Bot error: {e}")
    finally:
        # D-03: graceful shutdown of both systems
        logger.info("Shutting down...")
        heartbeat_task.cancel()
        try:
            await heartbeat_task
        except asyncio.CancelledError:
            pass
        ws_server.close()
        await ws_server.wait_closed()
        if not bot.is_closed():
            await bot.close()
        logger.info("Shutdown complete")


def main():
    asyncio.run(run())


if __name__ == "__main__":
    main()
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Discord API -> Bot | Bot token authenticates; interaction payloads from Discord |
| User -> Bot (via Discord) | User IDs in interactions must be checked against allowlist |
| config.json -> Bot | Local file, trusted but validates structure |
| bot/.env -> Bot | Contains Discord token secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | bot/.env | mitigate | Store Discord token in bot/.env only, add bot/.env to .gitignore, provide .env.example without real values |
| T-02-02 | Elevation of Privilege | BotConfig.allowed_guild_ids | mitigate | Three layers: (1) setup_hook syncs only to allowed guilds, (2) global_interaction_check rejects unauthorized guilds at runtime, (3) cog interaction_check as backup. Runtime check is authoritative. |
| T-02-03 | Spoofing | Discord interactions | accept | Discord API guarantees user.id and guild_id authenticity via bot token auth; no additional verification needed |
| T-02-04 | Tampering | config.json | accept | Local file on bot operator's machine; no remote write access. asyncio.Lock prevents corruption from concurrent save/reload. |
| T-02-11 | Denial of Service | AgentManager callbacks | mitigate | Callbacks wrapped in try/except so Discord API failures cannot crash agent lifecycle handling |
</threat_model>
