    **Step 4: Create bot/server.py** following RESEARCH.md Pattern 2 and Pattern 4:

    Create `AgentInfo` dataclass:
    ```python
    @dataclass
    class AgentInfo:
        websocket: ServerConnection
        machine_name: str
        platform: str
        last_pong: float  # time.time()
    ```

    Create `AgentManager` class:
    - `__init__(self, config: BotConfig)`: stores config, initializes `self.agents: dict[str, AgentInfo] = {}` (machine_name -> AgentInfo)
    - `async handler(self, websocket: ServerConnection)`: main per-connection handler:
      1. Call `_authenticate(websocket)` -- returns machine_name or None
      2. If None, return (connection already closed in _authenticate)
      3. Log registration with loguru: `logger.info(f"Agent registered: {machine_name} ({platform})")`
      4. Try `_handle_agent(websocket, machine_name)`, finally `_remove_agent(machine_name)`
    - `async _authenticate(self, websocket) -> str | None`:
      1. `asyncio.wait_for(websocket.recv(), timeout=config.registration_timeout)` -- TimeoutError -> close 1008 "Registration timeout", return None
      2. Try `parse_message(raw)` -- Exception -> send ErrorMessage(reason="invalid_message"), close, return None
      3. Check `isinstance(msg, RegisterMessage)` -- if not, send ErrorMessage(reason="expected_register"), close, return None
      4. Check `msg.secret != config.shared_secret` -- send ErrorMessage(reason="auth_failed", request_id=msg.request_id), close, return None
      5. Check `msg.machine_name in self.agents` -- send ErrorMessage(reason="machine_name_taken", request_id=msg.request_id), close, return None
      6. Add to self.agents: `self.agents[msg.machine_name] = AgentInfo(websocket=websocket, machine_name=msg.machine_name, platform=msg.platform, last_pong=time.time())`
      7. Send AckMessage(request_id=msg.request_id), return machine_name
    - `async _handle_agent(self, websocket, machine_name)`:
      1. `async for raw in websocket:` loop
      2. Parse message, handle HeartbeatPong (update last_pong), DisconnectMessage (break), log unknown types
    - `_remove_agent(self, machine_name)`:
      1. Pop from self.agents if present
      2. Log with loguru: `logger.info(f"Agent disconnected: {machine_name}")`
    - `async _heartbeat_loop(self)`:
      1. `while True: await asyncio.sleep(config.heartbeat_interval)`
      2. Get current time, iterate agents
      3. If `now - agent.last_pong > config.heartbeat_timeout`: add to dead list
      4. Else: try send HeartbeatPing(), on ConnectionClosed add to dead list
      5. For dead agents: close websocket, remove from self.agents, log warning

    Create `start_server(config: BotConfig)` async function:
    1. Create AgentManager(config)
    2. Set up cross-platform signal handling (asyncio.Event for shutdown, signal.signal for SIGINT/SIGTERM)
    3. Start heartbeat loop as asyncio task
    4. Start server with `async with serve(manager.handler, config.ws_host, config.ws_port)`
    5. `await shutdown_event.wait()`
    6. Cancel heartbeat task
    7. Log shutdown

    ```python
    """Entry point: python -m bot"""
    import asyncio
    from loguru import logger

    from bot.server import start_server

    def main():

    if __name__ == "__main__":
        main()
    ```

    **IMPORTANT anti-patterns from RESEARCH.md:**
    - Use `from websockets.asyncio.server import serve, ServerConnection` (NOT legacy `websockets.serve`)
    - Only add agent to `self.agents` AFTER successful auth (not before -- prevents heartbeat-during-registration race)
    - Always copy `request_id` from incoming message to response messages
    - Use `time.time()` for last_pong, not `asyncio.get_event_loop().time()`
    - Do NOT use `loop.add_signal_handler()` (fails on Windows) -- use `signal.signal()` instead

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket client -> server | Untrusted agent connects; must authenticate before any tracked state |
| JSON payload -> parse_message | Untrusted data parsed into typed models |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Spoofing | AgentManager._authenticate | mitigate | Verify shared_secret matches config before adding agent to tracked dict; reject with error + close on mismatch |
| T-01-05 | Denial of Service | AgentManager._authenticate | mitigate | 10s registration timeout via asyncio.wait_for(); connections that don't register are closed |
| T-01-06 | Denial of Service | AgentManager.handler | mitigate | Pydantic parse_message in try/except; malformed messages get ErrorMessage response, not crash |
| T-01-07 | Spoofing | AgentManager._authenticate | mitigate | Duplicate machine_name rejected with "machine_name_taken" error; prevents impersonation of existing agent |
| T-01-08 | Information Disclosure | ErrorMessage responses | accept | Error reasons like "auth_failed" reveal that the server exists, but this is acceptable for a personal-use tool on a known network |
</threat_model>
