    **Step 3: Create agent/client.py** following RESEARCH.md Pattern 3:

    Create `AgentClient` class:
    ```python
    class AgentClient:
        def __init__(self, config: AgentConfig, base_delay: float = 1.0,
                     max_delay: float = 60.0, jitter_max: float = 1.0):
            self.config = config
            self.base_delay = base_delay
            self.max_delay = max_delay
            self.jitter_max = jitter_max
            self._running = True
            self._websocket = None
    ```

    - `async run(self)`: main reconnect loop (per D-11, D-12):
      ```
      delay = self.base_delay
      while self._running:
          try:
              async with connect(self.config.bot_url) as websocket:
                  self._websocket = websocket
                  delay = self.base_delay  # Reset on successful connect
                  registered = await self._register(websocket)
                  if not registered:
                      continue  # Auth failed, retry with backoff
                  await self._message_loop(websocket)
          except (ConnectionClosed, OSError) as e:
              if not self._running:
                  break
              jitter = random.uniform(0, self.jitter_max)
              wait = min(delay + jitter, self.max_delay + self.jitter_max)
              logger.warning(f"Disconnected, reconnecting in {wait:.1f}s...")
              await asyncio.sleep(wait)
              delay = min(delay * 2, self.max_delay)
          finally:
              self._websocket = None
      ```

    - `async _register(self, websocket) -> bool` (per D-08, D-18, D-24):
      1. Create RegisterMessage with secret=config.shared_secret, machine_name=config.machine_name, platform=sys.platform
      2. Send via `websocket.send(msg.model_dump_json())`
      3. Receive response, parse with parse_message()
      4. If AckMessage: logger.info("Registered as {machine_name}"), return True
      5. If ErrorMessage: logger.error(f"Registration rejected: {msg.reason}"), return False
      6. Otherwise: logger.error("Unexpected response"), return False

    - `async _message_loop(self, websocket)` (per D-07):
      1. `async for raw in websocket:` loop
      2. Parse with parse_message()
      3. If HeartbeatPing: send HeartbeatPong(request_id=msg.request_id)
      4. Log other message types at debug level (future phases will add command handling)

    - `async stop(self)` (per D-25):
      1. Set `self._running = False`
      2. If `self._websocket` is not None and is open:
         - Send DisconnectMessage
         - Close websocket
      3. logger.info("Agent shutdown complete")

    **Step 4: Update agent/__main__.py** (per D-02):
    ```python
    """Entry point: python -m agent"""
    import asyncio
    import signal
    from loguru import logger
    from agent.config import load_agent_config
    from agent.client import AgentClient

    def main():
        config = load_agent_config()
        client = AgentClient(config)

        shutdown_event = asyncio.Event()

        def _signal_handler(*_):
            shutdown_event.set()

        signal.signal(signal.SIGINT, _signal_handler)
        signal.signal(signal.SIGTERM, _signal_handler)

        async def run():
            agent_task = asyncio.create_task(client.run())
            await shutdown_event.wait()
            await client.stop()
            agent_task.cancel()
            try:
                await agent_task
            except asyncio.CancelledError:
                pass

        logger.info(f"Agent starting: {config.machine_name} -> {config.bot_url}")
        asyncio.run(run())

    if __name__ == "__main__":
        main()
    ```

    **IMPORTANT from RESEARCH.md anti-patterns:**
    - Use `from websockets.asyncio.client import connect` (NOT legacy import)
    - Do NOT use `async for websocket in connect(...)` built-in reconnect (doesn't support re-registration)
    - Use `signal.signal()` not `loop.add_signal_handler()` (Windows compatibility)
    - Do NOT persist subprocess between messages (not relevant yet but avoid the pattern)
